# Localization review workflow

Before a language is released:

1. Add every UI key to the English and target-language JSON files.
2. Run `npm test` and confirm the locale key-parity test passes.
3. Review meaning, tone, numerals, punctuation, and terminology with a fluent speaker.
4. Check the game menu, setup, board, dialogs, event log, and winner summary at phone width.
5. Record the reviewer, date, and any unresolved wording below.

| Language | Reviewer | Date | Status / open items |
| --- | --- | --- | --- |
| Tamil | Pending native review | — | UI strings are present; review wording and small-screen layout before release. |
